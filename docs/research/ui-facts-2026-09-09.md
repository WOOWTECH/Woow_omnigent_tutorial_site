## Automations

清單頁：搜尋框 + `All` / `Active` / `Paused` 三個篩選頁籤，下方 `Suggestions`
提供三個範本：`Follow-up monitor`、`PR sweep`、`News digest`。
說明文字：「Run agent sessions on a recurring schedule. Tasks fire on a connected host.」

**New automation 對話框欄位（依序）**
1. `Name`（佔位 `daily-brief`）
2. `Prompt`（佔位 `What should the agent do each run?`）
3. `Runs with`（harness/agent 下拉）
4. `Model` / `Effort`（並排，皆預設 `Default`）
5. `Permission mode`（預設 `Default`）
6. `Frequency`（例 `Daily`）/ `Time`（例 `09:00 AM`）
7. `Host (optional)`（預設 `Resolve at fire time`）

**關鍵提示（原文）**
> Leave on Default to use the agent's configured model, effort, and permission mode.
> Automations run unattended, so a prompting mode (Manual or Plan) will wait for
> approval that never comes.

> Leave unset to run on your connected host when the task fires.

## Settings（11 個分頁）

`Account` · `General` · `Appearance` · `Git` · `Keyboard shortcuts` · `Import sessions`
（以上為個人）／ `Members` · `Policies` · `Sharing`（管理）／ `Archived sessions`（封存）

### General
- **Submit with ⌘ + Enter on desktop** — Off：Enter 送出、Shift+Enter 換行；
  On：Enter 換行、⌘+Enter 送出。
- **Always steer** — 後續訊息直接送進進行中的回合而非排隊；
  harness 支援時折進當前工作，否則在下一回合處理。

### Git
- **Always use a random worktree** — 在任何 git 工作區以隨機命名的新 worktree 起始
  新 session；Project 自己的 Random worktree 設定會覆寫此項。
- **Default base branch** — 命名新 worktree 分支時自動填入的基底；留空則不自動填。

### Appearance
Mode（System/Light/Dark）· Terminal theme（Match app/Light/Dark）· Color theme
（Theme palette「Omnigent」= the signature pink brand look；Accent `#11171C`；
Background tint `#FFFFFF`；Contrast 50）· Translucent sidebars ·
Default transcript view（Chat / Terminal）· Workspace panel（Open / Collapsed）·
Hide unconfigured harnesses · Interface font size / family ·
Code font size / family · Heavier code font · Export / Import / Reset to defaults

### Import sessions
「Pull your recent local chats from a machine you're running into Omnigent.
Sessions already imported are skipped.」
欄位：`Machine`（例 `Pi Web ChatGPT (pi1)` + `ONLINE` 徽章）、
`Harness`（`All harnesses`）、`How many recent sessions`（`Last 25`）、`Import` 按鈕。

### Members
表格欄位：`USERNAME` / `ROLE` / `LAST LOGIN` / `ACTIONS`（Reset、Remove）。
角色有 `Admin` 與 `Member`。右上 `Invite member`。

### Sharing
**Session sharing** 四段：
- `On` — 有 manage 權限者可任意層級分享（read / edit / manage），並可切換 public / workspace read
- `Read only` — 新分享上限為 read；edit 與 manage 會被拒絕
- `Read only (restricted)` — 唯讀，且工作目錄是家目錄或檔案系統根的 session 完全不可分享
- `Off` — 停用分享，Share 控制項隱藏

**Public access** 獨立開關：允許以連結公開唯讀分享。關閉後 Share 對話框的
Public access 切換會隱藏，新的公開分享被拒；**已公開的 session 在撤銷前仍維持公開**。

> 原文重點：「Changes affect only new shares — existing grants (including already-public
> sessions) keep working until revoked.」

### Policies
標題 `Global Policies`／說明「Global policies applied to all sessions.」
右上 `Add policy`，另有 `Refresh`。本站目前為空。

**內建目錄（25 條，依對話框順序）**
1. Limit Tool Calls Per Session — 以 session_state 持久化計數器限制整個 session 的工具呼叫總數
2. Detect Tool Call Retry Loops — 偵測代理以完全相同參數重試同一工具；重複 N 次後 ASK
3. Require Approval for File & Shell Operations — 任何檔案或 shell 工具呼叫前先要求核准
4. Block Specific Skills — 攔截 load_skill / read_skill_file，阻止載入特定 skill
5. Enforce Sandbox on Agent Start — 每次代理啟動強制指定沙箱設定（例 linux_bwrap）
6. Deny PII in LLM Requests — 掃描使用者訊息與 LLM 請求中的個資（SSN、信用卡、email、電話）
7. Session Cost Budget — 以累計 LLM 花費（USD）設閘；達硬上限後 DENY
8. Per-User Daily Cost Budget — 以擁有者當日（UTC）跨所有 session 的累計花費設閘
9. Google Drive / Docs / Sheets Access — 透過任何 Google MCP server 控管存取
10. Gmail Access — 預設允許讀取與草稿，阻擋寄送
11. Google Calendar Access — 預設唯讀
12. GitHub Repo & Branch Access — 跨 MCP 工具控管 GitHub 存取
13. Block Working Directory & Worktree Changes — 攔截 cd/chdir/pushd/popd、git -C、git worktree
14. Session Risk Score — 由高風險工具呼叫與敏感資料結果累積風險分數
15. Deny Trivial Tasks on Expensive Models — 以伺服器端 LLM 判定訊息為 TRIVIAL 或 COMPLEX
16. Intent Based Authorization — 以首則訊息為權威意圖，後續行為需符合該意圖
17. CEL Expression Policy — 以 CEL 運算式評估每個 policy 事件
18. LLM Prompt Classifier Policy — 由作者以自然語言提示描述判斷準則
19. Detect Task Switch — 判定訊息是延續當前任務或切換到新任務
20. Detect Agent Thrashing — 以滑動視窗追蹤工具結果，偵測反覆失敗
21. Block Dangerous Shell Commands — 安全指令放行，可回復的高風險指令 ASK 或 DENY
22. Limit Sub-Agent Dispatches Per Turn — 限制每回合派生子代理數，防止失控扇出
23. Require Purpose on Sub-Agent Dispatches — 每次派生須宣告用途（implement / review / explore / search）
24. Restrict Writes to Git Worktree — 阻擋 worktree 外的檔案寫入
25. Report-Only (Deny File Writes) — 拒絕所有會改檔的工具，只回報不動手

### Keyboard shortcuts（原樣）
**General**：新 session `⌘N`／命令面板 `⌘K`／顯示快捷鍵 `⌘/`
**In chats**：送出 `↵`／換行 `⇧↵`／回溯上一則提示 `↑`／下一則 `↓`／
接受核准提示 `⌘↵`／語音輸入 `⌘⌥V`／停止回應 `Esc`
**Navigation**：上一個 session `⌘↑`／下一個 `⌘↓`／跳到釘選 session `⌘⌥1…0`
**View**：切換對話側邊欄 `⌘⌥[`／切換工作區側邊欄 `⌘⌥]`
**Slash commands**（建議選單開啟時）：`↑↓` 移動／`Tab` 套用／`Esc` 關閉

## 截圖注意事項

側邊欄會顯示真實 Project 與 session 標題（含客戶名）。

其他畫面必須先收合側邊欄或事後遮蔽。Members 頁含真實帳號與 email，一律不截。
